Palmier Pro for Linux -- per-file license header templates
==========================================================

Every source file in the open-source components (Timeline_Editor, MCP_Server,
and Agent_Chat) MUST begin with a GPLv3 header. We use the standard SPDX short
identifier `GPL-3.0-or-later` as the first line so that automated license
scanners (e.g. `reuse`, GitHub's license detection) recognize the file, and we
follow it with the standard GPLv3 notice recommended by the Free Software
Foundation ("How to Apply These Terms to Your New Programs" in the LICENSE
file).

Replace <YEAR> with the year the file was created (or a range such as
2024-2025) and keep the copyright holder line consistent with the project.

--------------------------------------------------------------------------------
Minimal header (acceptable for short build/config files)
--------------------------------------------------------------------------------

At minimum, a file MUST carry the SPDX identifier on its first line:

  # SPDX-License-Identifier: GPL-3.0-or-later      (hash-comment files)
  // SPDX-License-Identifier: GPL-3.0-or-later     (C-style files)

Files that generate the closed-source Generative_AI_Service CLIENT stubs are
still GPLv3 (only the remote service is proprietary) and therefore use the same
headers above. See the NOTICE file for the open-source / closed-service split.
